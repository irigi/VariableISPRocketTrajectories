Space Chase

PURSUIT-EVASION IN FREE SPACE WITH VARIABLE-Isp PROPULSION

This interactive applet explores a pursuit-evasion problem between two spacecraft in gravity-free 2D space. Ship A (the evader) is trying to reach base Z and come to a stop there. Ship B (the pursuer) is trying to intercept A before it arrives.

Both ships use constant-power, variable specific impulse (Isp) engines — the same propulsion model studied in the accompanying manuscript. Under this model, optimal acceleration profiles are linear in time for each axis (a result from Pontryagin's Maximum Principle), and the fuel cost of a manoeuvre is determined by the integral of acceleration squared.

The applet solves for A's minimum-time brachistochrone to the base and then scans all possible interception times to find whether B can afford to intercept. Two victory conditions for the pursuer are considered:

V1 — Boarding: B must match both position and velocity with A (rendezvous). This requires solving a fixed-boundary optimal transfer.
V2 — Shooting: B only needs to reach A's position; velocity mismatch is allowed (fly-by intercept). This is a free-final-velocity problem and always costs less fuel than boarding.

Key parameters: power P, wet mass m_wet, dry mass m_dry, initial position and velocity. The fuel budget of each ship is Δ = 1/m_dry − 1/m_wet.

Use the sliders to change ship parameters, positions, and velocities. The trajectory map shows optimal paths, and the fuel plot shows B's required fuel cost as a function of interception time — where the curve dips below the dashed ΔB line, B can successfully intercept.

Based on the constant-power, variable-Isp trajectory model from VariableISPRocketTrajectories. See the manuscript (docs/manuscript.tex) for derivations and assumptions.

The applet runs entirely in the browser — no server required. Source code: space_chase.jsx.
